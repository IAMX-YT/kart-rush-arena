# Free resources for Rushroom

Checked October 12, 2026. Starting catalogue: https://github.com/ripienaar/free-for-dev . Provider pricing/license pages were checked directly; catalogue entries alone are not a guarantee of current terms.

| Resource | Useful for Rushroom | Free scope | Current status |
| --- | --- | --- | --- |
| [GlitchTip](https://glitchtip.com/pricing/) | Browser errors and reconnect failures | Hosted personal-project plan: 1,000 events/month. Events are shared across error/uptime/performance/release features. | Shortlisted from free-for-dev; account/integration not created. |
| [UptimeRobot](https://uptimerobot.com/pricing/) | Check public `/health` and alert when the backend is unavailable | Hobby/non-profit Free plan: 50 monitors, 5-minute checks; no credit card required. | Shortlisted from free-for-dev; monitoring not activated. |
| [Poly Haven](https://polyhaven.com/license) | Real PBR surfaces and outdoor HDR lighting | CC0 assets, usable commercially. | Already used locally; corrected the old night environment to a midday sky for this update. |
| [Kenney Input Prompts](https://kenney.nl/knowledge-base/game-assets-2d/using-input-prompts) | Consistent controller/help icons | CC0, free asset pack. | Additional game-specific resource; no need to load a full icon font into gameplay. |
| [Spector.js](https://github.com/BabylonJS/Spector.js) | Diagnose WebGL draw calls, textures and shaders | Open-source development tool. | Additional graphics debugging option; not loaded in the production client. |
| [glTF Transform](https://gltf-transform.dev/) | Optimize downloaded GLB geometry/materials/textures before shipping | Open-source toolchain. | Additional asset build tool; shortlisted for larger future game models. |

Immediate priorities are game assets and graphics/input optimization. Hosted monitoring and telemetry require a personal-project account; office Google credentials are not used. No paid subscription, new hosting account, or external telemetry integration was created. Existing Vercel/VPS costs are separate from these free assets/tools.
